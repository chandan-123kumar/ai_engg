## What Interviewers Test

| Round | What They Ask |
|-------|--------------|
| ML Fundamentals | "Explain bias-variance tradeoff", "Why does dropout work?" |
| Coding | Implement logistic regression, k-means, backprop from scratch |
| ML System Design | "Design a recommendation system for Netflix" |
| MLOps | "How do you monitor model drift in production?" |
| Behavioral | "Tell me about a model you deployed and what went wrong" |

## Key Principle
**Don't memorize answers — build intuition. Interviewers probe deeper when you sound scripted.**
